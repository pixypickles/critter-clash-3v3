- 報酬として隠し武器「競技手甲」を解放。白＋薄水色、最軽量・最短リーチ・最高速。左右交互の三連打で前進し、短剣系スキルを使用可能。通常大会の敵は使用しない。
- イベント完了後、時空の歪みに拳聖「キャット・リー」が出現。撃破で手甲専用「発勁」（短い踏み込み＋ガード貫通）を修得。
