けものブレイド・スポーツ Prototype v0.23

主人公を白＋水色のキツネへ変更し、主人公チームを「スノー・フォックス」に更新。ユニフォームは白地に青の縦ストライプです。カエルはチームメイトとして残しています。

RANK B大会後の修練ボス「森の荒武者」を倒すと、槍スキル「旋風突進」を獲得できます。槍を回転させながら防御して前進し、最後に長い突きを放つ技です。
