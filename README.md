# けものブレイド・スポーツ Prototype v0.32

- 槍・レイピアの突き判定を線分ベースに改善し、見た目上当たっているのに抜けるケースを低減
- タイトル画面のキツネを水色寄りに調整
- 小ボス戦は障害物・拠点なしの決闘フィールド
- 拠点を立体的な発光コア型スイッチに変更
- 実験武器：刀（赤）、ハルバード（緑）、レイピア（青）を追加
- 刀：狭く長い斬撃。回転斬り共有、専用カウンター「流し斬り」
- ハルバード：約90度の長い薙ぎ。槍系スキル共有、専用「返し薙ぎ」
- レイピア：槍より短く速い突き。踏込斬り共有、専用カウンター「幻影抜け」

## v0.26 変更点
- 刀の左手を「受け流し」に変更。短い受付時間で攻撃を無効化し、相手を小さくよろけさせます。
- レイピアの左手を「パリィ」に変更。通常攻撃は「斬り→突き」の高速2連撃です。
- 刀で見えていた不要な黄色い武器描画を修正しました。
- ハルバードは通常攻撃時に手元の一本そのものが振れる描画へ変更しました。
- 練習相手を攻撃的にし、カウンター／受け流し／パリィを試しやすくしました。


## v0.26 調整
- 練習相手の攻撃頻度を抑え、1回攻撃した後に距離を取り直す間を追加。
- 刀『流し斬り』とレイピア『幻影斬り』の成功ヒットに専用表示と衝撃エフェクトを追加。
- 槍／ハルバードの回転防御中は通常武器描画を隠し、回転中の一本だけを表示。ハルバードは武器長に合わせた回転描画。


## v0.28 調整
- 練習場CPUは実際に剣が届く間合いまで詰めてから攻撃し、攻撃モーション中は後退しないよう調整。
- 槍・ハルバードは通常時も回転防御時も持ち手を含めて同系色で発光。中心グリップだけ控えめに表示。

### v0.28
- 刀の受け流し／レイピアのパリィ成功時は攻撃を完全無効化し、相手だけを長めに硬直させ、自動の小反撃まで入るよう強化。
- RANK C/B/Aごとに3チームずつ専用CPUチームを用意。上位ランクでは刀・レイピア・ハルバードを含む編成と、カウンター・高速包囲・長柄制圧など明確な戦術テーマを採用。
- 通常対戦でも解放済みランクまでのチームが候補になる。

### v0.32
- レイピア本体を少し短く調整。
- 通常攻撃2段目の突きを短めの射程＋大きめの踏み込みに変更し、フェンシングらしい前進突きに調整。


## v0.32
- 両手持ちの「大剣」を追加。ハルバードより重く、移動・ステップが遅い重量級。
- 通常攻撃はゆっくりした広めの薙ぎ払い。
- 左手ボタンは刀身そのものを構える「大剣防御」。防御中は移動速度が大幅低下。
- 大剣の攻撃は防御されても相手を大きくノックバックさせる。
- 武器衝突でも大剣側は押し負けにくく、相手側のノックバックが大きい。
- スキルは「回転斬り」。大剣版は範囲・ノックバックが大きい代わりに発生と硬直が重い。


## v0.32 重量カラー
- 7武器を重量1〜7で統一。青系ほど軽く、赤系ほど重い虹色の発光に変更。
- 短剣=青紫(1)、レイピア=青(2)、刀=青緑(3)、片手剣=緑(4)、槍=黄(5)、ハルバード=橙(6)、両手剣=赤(7)。
- 重量値を武器衝突の押し合いにも反映。重い武器ほど相手を大きく弾き、自分は押し戻されにくい。
- 防御された時の押し込みも重量に連動。攻撃の一撃OUT性能そのものは全武器共通。
- 双盾は7武器の虹色重量表から外し、防具カテゴリとして扱う。


## v0.32
- 刀の刀身を緩やかに反った形へ変更。斬撃中も手に持つ一本が曲線として見える。
- 重量6の長柄武器をハルバードへ変更。槍の穂先に加えて横向きの斧刃を持つシルエットにした。
- ハルバードの性能は従来の重量6枠を継承し、長い薙ぎ払い・回転防御・槍系共有スキル・専用の返し薙ぎを使用する。
